# Tic Tac Toe Frontend

Two-player Tic Tac Toe built with React and Vite.

## Scripts
- npm install
- npm run dev     # start dev server at http://localhost:3000 (strict port)
- npm run build   # production build
- npm run preview # preview build at http://localhost:3000

## Features
- Two player mode (X/O)
- 3x3 board rendering
- Turn management with React hooks
- Win/draw detection (rows, columns, diagonals)
- Reset button
- Accessible button roles and aria-labels
- Light modern theme with #3b82f6 and #06b6d4 accents
